# crosstech-lp

**公開ページ：<https://wada3333.github.io/crosstech-lp/>**

中小企業向けの「バックオフィスDX・業務自動化コンサルティング」を題材にした、BtoB向けのデモLPです。
会社（株式会社クロステック・アーキテクツ）は架空です。

見どころは、問い合わせフォームの送信内容が **Google Apps Script 経由でスプレッドシートに記録される** ところです。
LPを作るだけでなく、問い合わせが来たあとの処理までつなげる例として作りました。

## 実装した機能

- **フォーム → スプレッドシートの自動記録**
  Fetch API で Google Apps Script（`doPost`）へ非同期送信し、スプレッドシートに1行ずつ記録します。送信中の表示と、完了時のトースト通知つき
- **送信まわりの対策**
  静的サイトでは送信先URLを隠せないため、受け取る側で被害を小さくしています
  - ハニーポット（人には見えない入力欄）と、3秒未満の送信の破棄
  - 必須・メール形式・文字数の入力チェック
  - 連投制限（同じメールアドレスは10分に1回、全体でも10分に10件まで）
  - 同時書き込みの直列化、数式インジェクション対策、記録件数の上限
- **ROI（費用対効果）シミュレーター**：スライダーを動かすと削減時間・削減額がその場で変わります
- **背景動画のファーストビュー**、ダーク／ライトの切り替え、コードブロックのワンクリックコピー
- **レスポンシブ対応**：スマホで横スクロールが出ないことを確認済み

## 使用技術

- HTML / CSS（CSS変数・Flexbox・Grid）/ JavaScript（ES6+、Fetch API、async/await）
- Google Apps Script・Google スプレッドシート（受け取り側。コードはこのリポジトリには含めていません）
- GitHub Pages
- 画像・動画：生成AIで作成

## 動かし方

ビルドは不要です。`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。
フォームは公開デモ用のスプレッドシートにつながっています。試すときは、実在の氏名・連絡先は入力しないでください。
